# TaskFlow — Simple & Smart To-Do List

A clean, responsive task management web application built with HTML, CSS, and JavaScript. TaskFlow helps users organize daily tasks, track progress, and stay productive through a simple and user-friendly interface.

## ✨ Features

- **Add Tasks:** Quickly add new tasks to your list.
- **Complete Tasks:** Mark tasks as completed when finished.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Filters:** View all, pending, or completed tasks.
- **Progress Statistics:** Track total, completed, and remaining tasks.
- **Local Storage:** Save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Designed to work across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Getting Started

No installation or additional dependencies are required.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.

## 💾 Data Storage

TaskFlow uses the browser's Local Storage to save tasks on the current browser and device. It does not currently use a backend server or database, and tasks do not automatically sync across devices.
